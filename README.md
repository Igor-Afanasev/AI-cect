# AI CECT rev.33 — методика работы

Самостоятельная методика подготовки спецификации, разработанная по фактической структуре исходной книги AI CECT rev.33 и инструкции пользователя.

- [Методика в Word](docs/AI_CECT_rev33_work_method.docx) — для редактирования и согласования.
- [Методика в Excel](docs/AI_CECT_rev33_work_method.xlsx) — 25 листов с родной шапкой и навигацией.
- [Методика в PDF](docs/AI_CECT_rev33_work_method.pdf) — для чтения.

Редакция 3.0 от 29.10.2026, проект для согласования. 22 раздела охватывают ввод данных, расчёты, проверку осуществимости, Pre-TR, Plant spec, управление изменениями и регистрацию в базе TR/DR.

В методике отдельно разобраны сохранённый пример и обнаруженное при статическом чтении VBA несоответствие ключа записи в базу. Макросы и запись в рабочую базу не выполнялись; исходный XLSM не изменён.

Excel- и Word-файлы проверены Microsoft Open XML SDK без ошибок.

[Предыдущая инструкция по образцу](docs/AI_CECT_rev33_assembly_instruction.xlsx) сохранена отдельно.
